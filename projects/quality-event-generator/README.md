 # Quality Event Analytics

 A learning and portfolio project that demonstrates how Python and pandas can be used to transform synthetic Quality Event data into validated analytics, risk classifications, management-review metrics, and visual outputs.

 ## Purpose

 This project is designed to build practical capability in:

 - Python
 - pandas
 - Data validation
 - Quality Risk Management logic
 - KPI-style analytics
 - Data quality exception handling
 - Data visualization
 - Reproducible analytics workflows

 The dataset is synthetic and is not derived from confidential company or patient data.

 ## Project Structure

 ```text
 quality-event-generator/
 ├── quality_event.py
 ├── quality_event_pandas.py
 ├── README.md
 └── output/
 ```

 ## Workflow

 The project generates synthetic quality events, validates the data, applies risk classifications, calculates management-review metrics, and writes analytical outputs and visualizations to the `output/` directory.

 ## Running the Project

 From this directory, run the scripts with Python:

 ```bash
 python quality_event.py
 python quality_event_pandas.py
 ```

 Review the generated files in `output/` after execution.

 ## Notes

 Results are intended for learning and portfolio demonstration. They should not be used as a substitute for production quality systems, validated analytical tools, or formal quality decisions.
